# ComicVerse AI

## Project Objective

ComicVerse AI is an AI-powered comic and graphic novel platform where users can read, upload, and interact with comics. The platform will include AI-powered recommendations, smart search, chatbot assistance, and community features.

---

## Planned Tech Stack

### Frontend

- React
- Tailwind CSS

### Backend

- FastAPI
- Python

### Database

- PostgreSQL

### AI

- OpenAI API
- LangChain
- ChromaDB
